# Clarity v0.28.0 release notes

> **Breaking release.** `clarity show` and `clarity watch` share one grammar now,
> and several v0.27.0 commands and flags were removed. Read the migration table
> before upgrading automated callers.

Under 0.x semver a minor bump signals breaking changes; this is the next release
after `v0.27.0`.

## Highlights

- **Unified `show` / `watch` grammar.** Both commands take positional
  `[paths…]` anchors and share the same lenses: `--reach`, `--depth`,
  `--collapse`, `--all`, `--between`, and `--module`.
- **New dependency reach.** `--reach up|down|both` walks the graph from an
  anchor — including *upstream* reach ("who depends on this file?"), which the
  old surface could not express.
- **Cleaner architecture views.** `--all --collapse` renders the whole tree
  folded into the modules declared in `.clarity/modules.json`.

## Breaking changes

### Removed commands

| Removed | Replacement |
|---|---|
| `clarity extensions` | `clarity languages --format json` (language + extension data) |
| `clarity why <from> <to>` | **Removed; no direct replacement.** `clarity show --between <a,b>` shows connecting *paths* but not the typed direct-edge / callsite detail `why` reported. |

### Removed flags (`show`)

| Removed | Replacement |
|---|---|
| `--input`, `-i <paths>` | positional `[paths…]` |
| `--file`, `-p <file>` | positional `<file>` with `--reach down` |
| `--level` | `--depth`, `-l` |
| `--scope` | `--reach down` |
| `--modules` | `--collapse` |
| `--direction`, `-d` | `--reach up\|down\|both` (with `--module`) |

### Removed flags (`watch`)

| Removed | Replacement |
|---|---|
| `--input`, `-i <paths>` | positional `[paths…]` |
| `--direction`, `-d` | `--orientation`, `-o` |

## New and changed

- `show`: `--reach`, `--all`, `--collapse` added; `--depth`/`-l` replaces
  `--level`; `--module` gained the `-m` short alias; `--prune` and `--also` now
  compose with `--reach` instead of the old `--file`.
- `watch`: gained `--reach`, `--depth`/`-l`, `--between`/`-w`, `--all`,
  `--collapse`, `--module`/`-m`, `--prune`, `--label`, and `--no-stats`, reaching
  parity with `show`. `watch` intentionally has no `--commit` — a live view is
  always the working tree.
- `languages`: gained `--format` (`text`, `json`); JSON output carries the
  language + extension data that `clarity extensions` used to print.
- `workspace`: description reworded; flags unchanged (still `--direction`/`-d`).

## Migration at a glance

| Old | New |
|---|---|
| `clarity show -i a b` | `clarity show a b` |
| `clarity show -p file.go` | `clarity show file.go --reach down` |
| `clarity show -p file.go --level 2` | `clarity show file.go --reach down --depth 2` |
| `clarity show --modules` | `clarity show --all --collapse` |
| `clarity show --module auth -d both` | `clarity show --module auth --reach both` |
| `clarity watch -i src` | `clarity watch src` |
| `clarity watch -d LR` | `clarity watch -o LR` |
| `clarity extensions` | `clarity languages --format json` |
